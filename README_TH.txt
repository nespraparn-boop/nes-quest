นักรบดินสอ 2B : NES Quest
================================

เวอร์ชัน: MVP PWA สำหรับ iPad
คลังข้อสอบพร้อมเล่น: 133 ข้อ

ไฟล์สำคัญ
- index.html      หน้าเว็บหลัก
- questions.js   คลังข้อสอบ
- manifest.json  ตั้งค่า PWA
- sw.js           ใช้งานออฟไลน์
- icon.svg        ไอคอน

วิธีทดลองบนคอม
1) เปิด Terminal/Command Prompt ในโฟลเดอร์นี้
2) รัน: python -m http.server 8080
3) เปิด http://localhost:8080

วิธีใช้บน iPad แบบแอป
1) อัปโหลดโฟลเดอร์นี้ขึ้น GitHub Pages / Vercel / Netlify (แพ็กเกจฟรีก็พอสำหรับใช้งานส่วนตัว)
2) เปิดลิงก์ด้วย Safari
3) Share > Add to Home Screen
4) หลังเปิดครั้งแรก ระบบจะ cache ไว้เพื่อใช้งานออฟไลน์

ข้อมูลความก้าวหน้า
- เก็บด้วย LocalStorage ในเครื่อง
- ไม่มีบัญชี ไม่มีค่า API
- Export/Import Progress เป็น JSON ได้

หมายเหตุ
- ข้อสอบในคลังเริ่มต้นมาจากชุดที่ผู้ใช้อัปโหลด
- ข้อที่ไม่มีเฉลยชัดเจนจะไม่ถูกนำเข้าพูลเล่น
- ข้อมูลชื่อบุคคล/นโยบาย/ข่าวอาจเปลี่ยนตามเวลา ควรรีวิวก่อนสอบจริง
